# Projetos Python

Este repositório reúne pequenos projetos que desenvolvo enquanto estudo a linguagem Python.

O objetivo é praticar conceitos fundamentais de programação, como lógica, condicionais, loops, funções e manipulação de dados.

Os projetos aqui variam de exercícios simples até pequenos jogos em terminal, servindo como registro da minha evolução enquanto programador.

Novos projetos serão adicionados conforme eu aprendo novos conceitos.
